## 本地启动（开发模式）

```bash
npm run dev          # 同时启动后端(8000)和前端Vite开发服务器
```

或直接运行生产模式（前端已构建，单端口访问）：

```bash
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
# 浏览器打开 http://localhost:8000
```

## AI 功能配置（可选）

设置以下环境变量后，AI 分类标签推荐、图片文字识别（OCR）自动启用：

```bash
set AI_API_KEY=你的API密钥          # OpenAI 兼容接口（Kimi/DeepSeek/通义均可）
set AI_BASE_URL=https://api.moonshot.cn/v1
set AI_MODEL=kimi-k2-0905-preview
set AI_VISION_MODEL=kimi-k2-0905-preview
```

未配置时 AI 按钮自动降级为规则推荐，不影响其他功能。

## 功能清单

- **提线索**：快速录入（30秒极简、语音转文字、拍照+图片文字识别、稍后补充）／完整录入（标题、内容、来源渠道、场景地点、获取时间、固定分类、关键词、可信度、图片附件）／AI 推荐分类与标签
- **看线索**：最新/热门/阅读/点赞四种排序，关键词搜索，分类+提交人+可信度+状态+时间范围多条件组合筛选，只看我关注的
- **互动**：点赞、收藏、关注提交人/分类（可设公开或隐藏）、仅自己可见的私人标签
- **管理端**：账号分配（无注册）、角色管理（一人可兼多角色）、线索状态管理（待补充→待核实→已核实→已归档）、一键导出 Excel
- **权限**：账号仅由管理员分配；线索仅提交人或管理员可编辑/删除

## 技术栈

前端 Vue 3 + Vant 4（移动端 H5/PWA）｜后端 FastAPI + SQLite（零部署依赖）｜单容器一体化部署
